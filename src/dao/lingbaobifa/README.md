## 目录

::: info

《灵宝毕法》，全称《秘传正阳真人灵宝毕法》，简称《灵宝毕法》，三卷。原题正阳真人钟离权（云房）著，纯阳真人吕嵒（洞宾）传，成书约在唐朝至五代时期，底本出自《正统道藏》太清部。

此书分三乘之法：卷上「小乘安乐延年法」四门，成就人仙；卷中「中乘长生不死法」三门，成就地仙；卷下「大乘超凡入圣法」三门，成就天仙。全书以《金诰》《玉书》《真原》《比谕》《真诀》《道要》六义，演说匹配阴阳、聚散水火、交姤龙虎、烧炼丹药、肘后飞金精、玉液还丹、金液还丹、朝元炼炁、内观交换、超脱分形等丹道要法，是钟吕一脉内丹学的奠基之作。
